An entry for the [make.fun](https://make.fun) competition
["What the Elevator Would Say"](https://make.fun/c/u-eager-stork-81-9647-what-the-elevator-would-say-90844958):
the funniest thing an elevator would say if it could talk, in one line of at
most 120 characters.

## The line

> Going up. Or down. Honestly, after 40 years, I just press whatever button feels emotionally correct.

100 characters — one line, in the elevator's own weary voice.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).
Python standard library only — no third-party dependencies.
